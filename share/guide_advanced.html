進階上手：互動網頁教材②與教材短影片④

給已經走過「新手上路」、知道 AI 會一步一步停下來等你確認的老師。這兩包和①③最大的不同是：AI 要能讀寫你電腦裡的資料夾，你也要自己在電腦上點兩下執行一些小程式（.bat 檔）。

選工具與資料夾→ ②網頁：規畫→試作→預覽→完整一節→ ④影片：安裝→規畫→預覽→錄音→產片
建議順序 先做②的一節，只在自己電腦預覽，不上線、不設計分。順利了再碰上線（GitHub）和計分（Firebase）。④步驟最多，建議做過②再開始。第一次各預留半天。

開始前：你需要會的三件小事

  • 找到資料夾：知道檔案存在哪裡，例如「文件\我的互動教材」。
  • 點兩下 .bat 檔：會跳出黑色視窗，跑完會顯示結果，按任意鍵關閉。
  • 看到錯誤不慌：把黑色視窗裡的紅字或最後幾行整段複製貼給 AI，問「這是什麼意思、我下一步要做什麼」。
三條安全規則 ①工作資料夾要另外新建，不要直接改技能包原檔或已上線的網站。②密碼、私鑰、Token 不貼給 AI。③AI 要你安裝東西、登入、發布或上傳時，先看懂它要做什麼再同意。

第 0 步：選一個能讀寫資料夾的 AI

工具怎麼讓 AI 用技能、讀到資料夾適合
Claude 桌面版用「新手上路」步驟 2 上傳過的技能，同一個帳號在桌面版也能用。②④要另外上傳 interactive-lesson-web.zip、textbook-to-short-video.zip（技能包目前試做驗證中，請先向作者索取）。開新對話後，用輸入框的 ＋ 選單 加入資料夾 Add folder，選你的工作資料夾。已經在用 Claude 的老師
Antigravity用 Antigravity 開啟工作資料夾。把 zip 解壓縮，將整個技能資料夾（例如 interactive-lesson-web）放進工作資料夾裡的 .agents\skills\。在對話面板輸入需求即可。習慣看檔案和資料夾的老師

按鈕名稱可能隨軟體改版而不同。只用網頁版 Claude 或 ChatGPT 也能做②④的「規畫」與「稿件」，但 AI 無法替你在電腦上建檔、執行和預覽，後半段要自己動手，比較吃力。

Part A　② 互動網頁教材

做完會有一節課的五種網頁：V 動畫、C 互學挑戰、S 上課簡報、R 補課包、T 教師大螢幕。

A1安裝 Python（只要一次）

點哪裡
到 python.org → Downloads → 下載 Windows 版並安裝。安裝畫面若有 Add python.exe to PATH，記得勾選。
貼什麼
開始選單搜尋「命令提示字元」並打開，輸入 python --version 後按 Enter。
會看到什麼
出現 Python 3.x.x。若顯示找不到指令，重開電腦再試；還是不行，把畫面文字貼給 AI 問。

A2建立工作資料夾，請 AI 先做「單節規畫」

點哪裡
新建一個資料夾，例如 文件\我的互動教材，把已確認的教案（新手上路做的 Word）和課本頁放進去。依第 0 步讓 AI 能讀寫這個資料夾。
貼什麼
按「複製」，改黃色【】後送出：
請使用 interactive-lesson-web 技能，替【科目／單元】製作一節可上課的互動網頁教材。 已確認的教案和課本頁：在這個工作資料夾裡的【檔名】。 學生與設備：【年級、程度、人數；幾人一台平板；有沒有投影和網路】 每節：【幾分鐘】 語音：先用瀏覽器朗讀，之後再決定要不要錄音。 計分：先用本機示範，不設定 Firebase。 發布：這次先不上線。 請先做單節規畫：V 動畫分幾段、C 互學挑戰做什麼、S/R/T 怎麼配合。做完停下給我看。 規畫通過後，再把技能包的 starter 複製到這個工作資料夾裡的新資料夾試作。 每一步告訴我「做完會看到什麼」，並分清楚已測、未測、待我確認。
會看到什麼
一份單節規畫：每段動畫畫什麼、學生在哪裡作答、挑戰怎麼玩、這節 50 分鐘怎麼排。看看是不是你想教的樣子，有意見就直接說。

A3確認規畫 → 試作動畫 V 和挑戰 C

貼什麼
按「複製」，貼上後送出：
規畫確認。請先做 V 動畫和 C 互學挑戰，做完告訴我要按哪個檔案預覽。
點哪裡
AI 做完後，到它建立的專案資料夾，點兩下 預覽.bat。
會看到什麼
黑色視窗顯示 預覽：http://127.0.0.1:8765/，瀏覽器自動打開首頁。點 V、C 實際操作看看。這個黑色視窗不要關，關了網頁就停了；看完再關。
試用小技巧 動畫每段結尾要答對才能往下。自己檢查時，可在網址最後加 ?unlock=1 直接切段。直接點兩下 .html 檔會是空白，一定要用 預覽.bat 開。

A4回饋修改 → 完成整節五種頁面

貼什麼
有要改的地方，用「哪一頁、哪一段、改成什麼」描述，例如：
V 第 2 段的箭頭方向反了，應該從【左】流向【右】；C 第 3 題的提示太難，改成先提醒學生看【哪裡】。
V、C 都滿意後：
V 和 C 確認。請完成 S 簡報、R 補課包、T 教師大螢幕，並依技能的巡檢清單檢查電腦和手機畫面。
會看到什麼
再按一次 預覽.bat，首頁五個入口都能打開。AI 會附一份檢查紀錄，寫明哪些測過、哪些還沒測。到這裡就能在教室用投影上課了。

A5（選用）全班手機送成績到教師大螢幕：Firebase

點哪裡
打開技能包裡的 interactive-lesson-web\Firebase引導提示詞.txt，全選複製。
貼什麼
貼給 AI，把【課程代碼】【工作資料夾位置】填好。AI 會一次只帶一步，建立專案、登入都由你自己在 Firebase 網站操作。
會看到什麼
約 20～30 分鐘後，用兩台裝置測試：學生頁送出成績，教師大螢幕收得到。過程中若網站要你綁付款方式，先停下來問人。

A6（選用）放上網路讓學生用網址打開：GitHub Pages

需要
GitHub 帳號和 Git 程式。第一次設定建議請熟手陪同，或請 AI 依技能的「GitHub Pages與更新」一步一步帶你。
貼什麼
按「複製」，貼上後送出：
我要把這節網頁放上 GitHub Pages。請依技能的「GitHub Pages與更新」說明，一次只帶我做一步。帳號登入和建立 repo 由我自己操作，你不要替我推送。
會看到什麼
設定好後，之後每次更新點兩下 更新網站.bat：它先列出要更新的檔案，你輸入 PUBLISH 才會真的上傳。上傳後等幾分鐘，用網址實際打開檢查，不要只看黑色視窗說成功。

Part B　④ 教材轉短影片

做完會有 3～5 分鐘的卡通教學影片（HQ 版和 LINE 小檔版）和字幕檔。旁白由你在 Google AI Studio 網頁自己產生，不需要 API 金鑰。

B1安裝 Python 和 ffmpeg（只要一次）

點哪裡
Python 同 A1。ffmpeg：開始選單搜尋「命令提示字元」並打開。
貼什麼
winget install -e --id Gyan.FFmpeg，按 Enter，問你是否同意時輸入 Y。裝完關掉這個視窗、重開一個，輸入 ffmpeg -version。
會看到什麼
出現 ffmpeg 的版本資訊。如果顯示 winget 無法辨識，請 AI 帶你用下載壓縮檔的方式安裝。

B2建立影片專案，裝好工具

點哪裡
解壓縮 textbook-to-short-video.zip，把裡面的 templates\starter 整個複製到新位置，改名為例如 文件\我的教學短影片。用記事本打開裡面的 project-env.bat，把最後的 my-course 改成你的課程英文簡稱（例如 electric-101），存檔。接著點兩下 SETUP.bat。
會看到什麼
黑色視窗下載套件，最後列出檢查結果（Python 套件、ffmpeg、瀏覽器、字型）。有「錯誤」就把整段貼給 AI。之後想再檢查，點 CHECK_ENV.bat。

B3先看內建示例，確認工具能動

點哪裡
點兩下 PREVIEW.bat，輸入示例課程前面的編號。
會看到什麼
瀏覽器打開預覽頁，可以選幕、拖時間軸。示例沒有錄音，只是確認工具正常。

B4請 AI 規畫與寫稿（三次確認）

點哪裡
依第 0 步讓 AI 能讀寫「我的教學短影片」資料夾，把課本頁放進去。
貼什麼
按「複製」，貼上後送出：
請使用 textbook-to-short-video 技能，製作【科目／單元】的教學短影片。 學生：【年級、程度】 教材：這個資料夾裡的【檔名】，印刷頁【幾～幾】。 這個資料夾就是影片專案（已從 starter 複製並完成 SETUP），請在 courses 裡建立我的課程。 每集 3～5 分鐘；角色與風格：請先提案給我選。 請依技能的階段做：先做教材摘要和覆蓋對照表 → 停下；我確認後做分集大綱 → 停下；再確認後寫稿件與分鏡 → 停下。 課本圖請重畫。不要呼叫任何語音 API，也不要上傳。
會看到什麼
依序是：①摘要和覆蓋表（課本每一項內容排在哪一集）→ ②每集大綱 → ③每一幕的旁白和畫面。每一步都要看過、回覆確認，AI 才會往下做。

B5看動畫預覽，確認後才錄音

點哪裡
AI 做好動畫後，點兩下 PREVIEW.bat，選你的那一集。
會看到什麼
每一幕的畫面隨旁白出現（還沒錄音，時間是估計的）。檢查專業內容、圖的方向、字有沒有被擋。有問題告訴 AI「第幾幕哪裡要改」。畫面和旁白都滿意才進下一步，因為改旁白就要重錄。

B6到 AI Studio 產生旁白並下載

點哪裡
點兩下 RUN_TTS.bat → 選集數 → 選 1（匯出本次錄音稿）。打開該集 audio\本次錄音清單.md，照清單逐份處理 旁白稿_host_1.txt 等檔案：
貼什麼
到 aistudio.google.com/generate-speech（用自己的 Google 帳號）。稿件裡「風格欄」的文字貼到風格說明處，「正文欄」以下的文字貼到要唸的內容。選定音色後產生，聽一遍再下載。
會看到什麼
下載的音檔改名成清單寫的檔名（例如 full_host_1.wav），放進該集的 audio 資料夾。同一角色整門課用同一個音色，記下來告訴 AI 寫進設定。

B7切音、逐幕聽、登記確認

點哪裡
RUN_TTS.bat → 選 2（切整份音檔）。再開 PREVIEW.bat，每一幕按播放聽：開頭、結尾、數字單位、問答角色有沒有對。全部聽完後，RUN_TTS.bat → 選 3，輸入 LISTENED。
會看到什麼
切音成功會顯示「已切 N 段」。若說停頓不足或靜音，回 AI Studio 重產那一份（句子之間停久一點）。最後出現「已記錄本次聽檢確認」。

B8產出影片

點哪裡
點兩下 BUILD_VIDEO.bat，選集數，等它跑完（幾分鐘）。
會看到什麼
該集 output 資料夾裡有 _hq.mp4（品質較好）、_line.mp4（小檔，方便傳 LINE）和 .srt 字幕。完整看一遍：聲音、畫面、字幕對得上，問答公布答案正確。
要放 YouTube？ 最簡單是自己到 YouTube Studio 手動上傳 HQ 版，先設「不公開」，字幕上傳同一次產生的 .srt。技能內的自動上傳工具需要另外設定 Google 授權，熟手再用。

交出去之前：老師的檢查

  • 網頁：電腦、平板、手機都打開看過；動畫每段的問題和答案正確；學生頁看不到教師答案。
  • 網頁上線：用實際網址打開，不只看「推送成功」。
  • 影片：專有名詞、數字單位、圖的方向和課本一致；字幕和聲音同步；完整播放過一次。
  • 課本原圖沒有直接貼進網頁或影片（都要重畫）；沒有學生個資。

卡住了怎麼辦

狀況這樣做
點 .bat 後黑色視窗一閃就關在資料夾空白處按右鍵 → 在終端機中開啟，輸入 .\預覽.bat（換成那個 .bat 的檔名）按 Enter，視窗就會留著顯示錯誤，再把訊息貼給 AI。
顯示找不到 python 或 ffmpeg安裝後要關掉舊的黑色視窗再開新的；還是不行就重開電腦，再試 python --version、ffmpeg -version。
網頁打開是空白不要直接點 .html，用 預覽.bat。改了內容沒變化，就按 Ctrl+F5 重新整理。
AI 說讀不到資料夾確認已依第 0 步加入資料夾，或檔案真的放在那個資料夾裡。
影片工具說「須為1～4個」「14字內」這一幕放太多東西了。請 AI 拆成兩幕或改短，不要硬塞。
改了旁白後，切音說要重錄這是正常保護：舊錄音已移到「舊錄音」資料夾。照新的錄音清單重產。
Firebase 或 GitHub 要付款、要權限、看不懂先停下，不要一直按「同意」。截圖問熟手，或貼給 AI 問這一步是做什麼的。
更多細節 每包資料夾裡都有更完整的說明：②看 interactive-lesson-web\SKILL.md 與 references；④看 templates\starter\開始使用.md。工具只支援 Windows 的 .bat；Mac 的老師請 AI 依「開始使用」改用終端機指令。
