重點一：石油的三大族

族別分子式形狀特性
石臘油族CₙH₂ₙ₊₂鏈狀揮發性佳、熱值高 → 內燃機燃料
石腦油族CₙH₂ₙ環狀燃燒穩定 → 防爆震燃料
芳香油族CₙH₂ₙ₋₆／CₙH₂ₙ₋₁₂苯環α 甲基奈 → 測柴油著火性

重點二：汽油的種類

依提煉方法

  • 天然汽油：天然氣加壓冷凝，揮發性極高
  • 直餾汽油：原油蒸餾，37～223℃
  • 裂煉汽油：高溫高壓分解重組，抗爆性佳

依含鉛量

  • 含鉛：加四乙基鉛 → 抗爆、潤滑汽門座；有毒、損壞觸媒
  • 無鉛：加 MTBE；臺灣 2001.1.1 起全面無鉛
  • 🌏 環境教育：一項政策，讓空氣裡的鉛大幅減少

重點三：揮發性要「配合地區」

❄️

低溫地區 → 揮發性高

冷車好發動、加速輕快、不易沖淡曲軸箱機油

☀️

高溫地區 → 揮發性低

避免油管內汽油汽化成氣泡 → 氣阻現象

口訣：冷地高揮發、熱地低揮發

重點四：比重與 API 度（式 3-1）

API 度 ＝ 141.5 ÷ 比重 － 131.5

比重 ＝ 141.5 ÷（API 度 ＋ 131.5）

車用汽油：比重 0.68～0.78、API 度 55～75，兩者成反比

例 1：比重 0.72 → API 度 ＝ 196.5 － 131.5 ＝ 65

例 2：20 公升、API 度 68.5 →
比重 ＝ 141.5 ÷ 200 ＝ 0.7075
重量 ＝ 20 × 0.7075 ＝ 14.15 kg

Q1 汽油怎麼來？

原油加熱進分餾塔，37～223℃ 收集＝直餾汽油

Q2 為什麼無鉛？

鉛有毒、會損壞觸媒轉化器，2001 年停用

Q3 冬天難發動？

低溫汽油不易汽化 → 冷地要用高揮發性汽油
